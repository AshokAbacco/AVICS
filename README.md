# Accident Vehicle Insurance Claim Management System (AVICS)

Third Party Motor Accident Insurance Claim Software — enterprise claim management platform.

## Structure

```
AVICS/
  client/     React (Vite) + Tailwind CSS UI — fully functional with dummy data
  server/      Express.js server scaffold (no database/APIs, per project scope)
```

## Quick Start

### Frontend

```bash
cd client
npm install
npm run dev
```

Runs at `http://localhost:5173`. Log in with any email/password.

### Backend

```bash
cd server
npm install
npm run dev
```

Runs at `http://localhost:5000`.

## Modules

Dashboard, Case Management, Victims, Vehicles, Hospitals, Police, Court, Advocates,
Documents, Compensation, Reports, Users, Notifications, Audit Logs, Calendar,
Settings, Profile.

## Tech Stack

**Frontend:** React.js (Vite), Tailwind CSS, React Router DOM, Lucide React Icons,
Axios, React Hook Form, Framer Motion, Recharts

**Backend:** Node.js, Express.js, CORS, dotenv, Nodemon
